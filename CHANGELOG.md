## [1.0.0] - 2026-10-10

- Convert tabular data between CSV/TSV, JSON, NDJSON, XLSX, XLS (read), SQL, Markdown and HTML via a shared table model.
- Library API (`convert` / `read` / `write`) and a command-line tool.
- Optional type inference, encoding detection and OWASP CSV-injection escaping on write.
- Zero runtime dependencies; ESM and CJS builds with TypeScript types.
